Cómo leer este informe y de dónde salen los números.

Fuente: Graph API de Meta (Page Insights) del fanpage Ferre Experto Pacasmayo. Fecha de corte: —. Actualizado: —.

  • Views: veces que se vieron las publicaciones del fanpage.
  • Viewers: personas únicas que vieron contenido.
  • Visits: visitas a la página del fanpage.
  • Follows: seguidores netos ganados en el período.
  • Viewers: personas únicas que vieron una publicación; Meta no expone alcance por publicación vía API.
  • Interacciones: reacciones + comentarios + compartidos.
  • Engagement: interacciones divididas entre alcance o, si no hay alcance, entre views. Se muestra “—” cuando no hay base comparable.

Las métricas por publicación son acumuladas (lifetime) hasta la fecha de corte, no solo del mes en que se publicaron. El mes en curso se marca como parcial y no se compara como un mes cerrado.

La audiencia corresponde a los seguidores del fanpage y es una foto fija al corte; no cambia con el selector de mes. La API puede no devolver todos sus desgloses.
